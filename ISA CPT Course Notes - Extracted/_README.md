## Notes

- **Reading order** — text flows title → left column → right column per slide.
- **Wording** — taken verbatim from each slide's text layer where it has one. Text that lived only inside a picture was OCR'd and can lose spaces between words (e.g. `FattyAcids`) or, on a dense data table (e.g. the AMDR nutrition table), come through as a flat list of the cell values rather than a real table.
- **Removed** — textbook page/figure references (`(Pg 62)`, `[PG 341-346]`, `(Refer to Figure 5-4)`…); the *Sports International Academy* logo; the *ISA Certified Personal Trainer Course* cover lines; slide numbers; image links. *Content Covered* / agenda slides are omitted (the `## Page N` heading stays, marked, so numbering still matches the PDF).

`_build.py`, `_polish.py`, `_strip_images.py` reproduce this from the source PDFs. The per-slide `images/` folders still hold every extracted picture but nothing links to them any more.
