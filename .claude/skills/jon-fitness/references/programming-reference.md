# Programming Reference — condensed, cited

A work aid: the most-used numbers with their source pages. **Verify anything
load-bearing against `references/isa-cpt/` before you rely on it** — these are
compressed and the source wording sometimes carries conditions this table drops.

Citation format: *(WkNN Ch## pN)*.

## 1. Resistance training variables by goal — Table 9-12 *(Wk07 Ch11 p16)*

| Goal | Sets | Reps | Rest | Intensity (%1RM) |
|---|---|---|---|---|
| General muscular fitness | 1–4 | 8–15 | 2–3 min | 20–70% |
| Muscular endurance | 2–3 | ≥12 | ≤30 s | ≤67% |
| Muscular hypertrophy | 3–6 | 6–12 | 30–90 s | 67–85% |
| Muscular strength | 2–6 | ≤6 | 2–5 min | ≥85% |
| Power — single-effort | 3–5 | 1–2 | 2–5 min | 80–90% |
| Power — multiple-effort | 3–5 | 3–5 | 2–5 min | 75–85% |

## 2. Resistance FITT-VP — Table 11-10 *(Wk07 Ch11 p29–31)*

- **Frequency:** each major muscle group 2–3 d/wk; 48–72 h between sessions for a muscle group *(p11)*.
- **Intensity:** 60–70% 1RM novice→intermediate for strength; ≥80% experienced; 40–50% older adults / sedentary beginners; <50% for muscular endurance.
- **Reps:** 8–12 strength/power (most adults); 10–15 middle-aged/older beginners; 15–25 endurance.
- **Sets:** 2–4 most adults; a single set can be effective for novice/older; ≤2 for endurance.
- **Rest:** 2–3 min between sets.
- **Type:** each major muscle group; multi-joint (agonist + antagonist) for all adults; single-joint after multi-joint for that group; any equipment / bodyweight.
- **Progression:** gradually add resistance and/or reps and/or frequency.

## 3. Tempo *(Wk07 Ch11 p17)*
1–3 s concentric · 2–4 s eccentric · 4–8 s controlled reps effective for strength · ~6 s reps good for new exercisers.

## 4. Exercise order *(Wk07 Ch11 p13)*
Multi-joint before single-joint · alternate upper/lower · alternate push/pull (agonist/antagonist) · supersets / compound sets / circuits as options · power/structural (axial-loaded) exercises early when fresh.

## 5. Progression methods *(Wk07 Ch11 p7, p19–20)*
- **2-for-2 rule:** if the client exceeds the target reps by ≥2 on the last set for 2 consecutive sessions → increase load.
- **Double progression:** work up the rep range at a fixed load, then increase load and drop back to the bottom of the range.
- **Load increment:** ~5% *(p7; also Wk04 Ch8 p65 SPORD/overload)*.
- **Progression continua:** bodyweight → machine → free weight; uniplanar → multiplanar; supported → unsupported; isolation → multi-joint; bilateral → unilateral; stable → unstable.

## 6. Periodization *(Wk07 Ch11 p42–46)*
Macrocycle (whole plan) → mesocycle (training block, ~weeks–months) → microcycle (~1–4 weeks). Linear (volume ↓ / intensity ↑ over time) vs undulating (varies within the week). Typically only core (multi-joint) exercises are periodized. Main benefit: reduced overtraining risk via planned recovery. Use when horizon is ≥~3 months or there's an event date.

## 7. ACE IFT — Muscular Training phases *(Wk02 Ch2 p10–14; Wk07 Ch11 p21–32)*

| Phase | Use when | Focus | Load |
|---|---|---|---|
| **Functional** | Poor stability/mobility, deconditioned, returning from injury, older adult | Postural stability + kinetic-chain mobility; core, balance; stabilize lumbar first, then distal | Bodyweight / body-segment |
| **Movement** | Stability adequate, movement patterns need work | 5 primary movement patterns (push, pull, bend-and-lift, single-leg, rotation) in varied planes; reps > intensity | Light, 50–60% 1RM |
| **Load/Speed** | Patterns competent, goal needs force/speed | External load for strength / hypertrophy / endurance / power; add SAQ & plyo for athletes | Per Table 9-12 / 11-10 |

Functional & Movement exercises stay useful as warm-up/cool-down once the client progresses *(Wk07 Ch11 p18)*.

Mobility–stability by joint *(Wk03 Ch9 p41; Wk07 Ch11 p22)*: glenohumeral = mobility · scapulothoracic = stability · thoracic spine = mobility · lumbar = stability · hip = mobility · knee = stability · ankle = mobility · foot = stability.

## 8. Five primary movement patterns *(Wk02 Ch2 p12)*
Push · Pull · Bend-and-lift (squat) · Single-leg · Rotation. (Some slides also list "range of movement".) Program all five, in varied planes.

## 9. Cardiorespiratory — evidence-based FITT-VP *(Wk05 Ch8 p10)*

| | |
|---|---|
| Frequency | ≥5 d/wk moderate, or ≥3 d/wk vigorous, or a combo |
| Intensity | Moderate–vigorous for most adults; light–moderate for deconditioned |
| Time | 30–60 min/d moderate; 20–60 min/d vigorous; <20 min/d still helps the previously sedentary |
| Type | Rhythmic, continuous, large-muscle-group activity |
| Volume | ≥500–1000 MET-min/wk; ≥150 min/wk moderate; ≥7000 steps/d |
| Pattern | Continuous, intervals, or accumulated ≥10-min bouts (shorter still helps deconditioned) |
| Progression | Start low, go slow; increase steps ≥2000/d toward target; ≤10%/wk *(p26)* |

## 10. Cardio intensity — HR methods *(Wk05 Ch8 p13–20)*

- **APMHR:** 220 − age (overestimates in young, underestimates in older); alternatives 206.9 − 0.67·age, 208 − 0.7·age.
- **Karvonen / HRR:** THR = (HRR × %intensity) + RHR, where HRR = MHR − RHR.
- **Three-zone model (Table 8-11):**

| Zone | Metabolic marker | %HRR | %MHR | RPE (0–10) | Talk test |
|---|---|---|---|---|---|
| 1 | < VT1 | 40–60% | 64–76% | 3–4 | can talk comfortably |
| 2 | VT1 to < VT2 | 60–90% | 77–95% | 5–6 | not sure if comfortable |
| 3 | ≥ VT2 | 90–100% | ≥96% | 7–10 | definitely can't talk comfortably |

- If on a beta blocker / BP med → use RPE or the talk test, not %MHR *(Wk04 Ch5 p15–16)*.

## 11. ACE IFT — Cardiorespiratory phases *(Wk02 Ch2 p8; Wk05 Ch8 p28–39)*

| Phase | Client | Frequency | Duration | Intensity | Test | Progress when |
|---|---|---|---|---|---|---|
| **Base** | Physically inactive | 2–3 d/wk | 10–15 min → build | Below talk-test / VT1, RPE 3–4 | none | ≥20 min continuous below the talk-test threshold |
| **Fitness** | Regular exerciser, health/fitness goals | 3–5 d/wk | ≥20 min | Steady state + Zone-2 intervals | VT1 (talk test) | goals met / ready for event focus |
| **Performance** | Endurance-event / competitive | 5–7 d/wk | >30 min | + near-/maximal intervals, HIIT, work at/above VT2 | VT2 threshold test | — |

Session = warm-up 5–10 min + conditioning + cool-down 5–10 min *(Wk05 Ch8 p41)*. Interval work:rest ratios 1:1 to 1:3 depending on phase/intensity *(p42)*. Performance volume "Rule of 3": weekly volume ≈ 3× race duration *(Wk05 Ch11 p34)*.

## 12. Flexibility FITT-VP — Table 11-7 *(Wk07 Ch11 p25)*

Frequency ≥2–3 d/wk (daily best) · Intensity: stretch to tightness / slight discomfort · Time: hold static 10–30 s (older adults 30–60 s); PNF = 3–6 s contraction (20–75% MVC) then 10–30 s assisted stretch · Type: static / dynamic / ballistic / PNF all effective, one per major muscle-tendon unit · Volume ~60 s total per exercise · Pattern 2–4 reps each · most effective when the muscle is warm.

## 13. Balance / neuromotor FITT-VP — Table 11-8 *(Wk07 Ch11 p27; task mods p26)*
≥2–3 d/wk · ≥20–30 min/d · motor-skill (balance, agility, coordination, gait) + proprioceptive + multifaceted (tai chi, yoga) · progression seated → standing → in-motion; modify arm position, surface, vision, single- vs multi-task · strongest evidence in older adults / fall-risk.

## 14. Plyometrics *(Wk07 Ch11 p33–38)*
Frequency 1–3 ×/wk, 48–72 h recovery · drills early in session after warm-up · teach landing technique first · volume (foot contacts/session): beginner 80–100, intermediate 100–120, advanced 120–140 (Table 11-13) · intensity factors: points of contact, speed, height, body/added weight, complexity (Table 11-12) · progression jumps-in-place → linear → multidirectional → bounds → depth jumps.

## 15. Speed, agility, quickness *(Wk07 Ch11 p39–41)*
Frequency 1–3 ×/wk, non-consecutive · duration/energy system: <10 s phosphagen, 10–60 s glycolytic (Table 11-16) · stationary drills 1–3 sets × 10–15 s → 20–30 s; dynamic 1–3 sets × 20–30 yd → 100 yd · 2–3 min rest between reps.

## 16. Recovery *(Wk07 Ch11 p47–48)*
Minimum dose to maintain cardiometabolic health/weight ≈ 1 mile+/day (~8 mi/wk); low-dose HIIT ~12 min/wk improves cardiometabolic health; combine cardio + resistance to resist detraining. Recovery FITT: frequency (per week / microcycles per year), time (between bouts / between sessions), type (active vs passive), intensity.

## 17. Special populations — adjustments (start from the healthy-adult guideline, then apply these)

### Youth — Table 14-2 *(Wk08 Ch14 p4–9)*
Aerobic daily (moderate–vigorous, vigorous ≥3 d/wk), as part of ≥60 min/day total activity · resistance ≥3 d/wk, 8–15 submaximal reps to moderate fatigue with good form · bone-strengthening ≥3 d/wk · **no 1-RM lifts, no sudden explosive moves, no competition during resistance work** · growth plates not fused · bodyweight/free-weight over machines · fun, varied, periodized to avoid overuse.

### Pregnancy — Table 14-3 *(Wk08 Ch14 p10–16)*
Previously active may continue as tolerated; previously inactive start low, progress to moderate · talk test, stay below VT1 · aerobic ≥3–5 d/wk, moderate (3–5.9 METs, RPE 12–13/20), ~30 min/day → ≥150 min/wk · resistance ≥2–3 d/wk, 8–10 or 12–15 reps to moderate fatigue, 1 set beginner / 2–3 intermediate–advanced · **avoid supine after ~20 weeks, contact sports, fall-risk activities, extreme heat** · use PARmed-X · know contraindications & termination signs *(p15)*.
Postpartum *(p17–19)*: physician clearance, start slow (duration → frequency → intensity), slower after C-section, watch for diastasis recti, add posterior-chain/posture work.

### Older adults — Table 14-4 *(Wk08 Ch14 p20–25)*
Aerobic ≥5 d/wk moderate or ≥3 d/wk vigorous, 30–60 min/day, RPE 5–6 moderate / 7–8 vigorous (0–10) · resistance ≥2 d/wk, **40–50% 1RM for beginners** → progress to 60–80%, 1–3 sets × 8–12, 8–10 exercises · flexibility ≥2 d/wk, hold 30–60 s · **balance training (with support), prolonged warm-up/cool-down, modify movement assessments** · otherwise similar to general population; watch chronic conditions.

### Obesity *(Wk09 Ch12 p25–34)*
Behavioural weight loss = caloric deficit 500–1000 kcal/day (→ 1–2 lb/wk) + increased physical activity + behavioural strategies; refer to an RD for the diet · cardio ≥5 d/wk, moderate **below VT1 / RPE 3–4**, 30–60 min/day → 150–250 min/wk, low-impact rhythmic (walk, cycle) · muscular 2–3 d/wk, 8–12 reps × 2–4 sets, full body ~20–30 min, all major muscle groups, machines + free weights · maintaining current weight can count as progress · bariatric surgery last resort (BMI ≥40, or ≥35 with a comorbidity).

## 18. Chronic disease — retrieve the per-condition table, don't work from memory *(Wk10 Ch13)*

General approach *(p6)*: begin with the healthy-adult guideline, then modify for disease characteristics, safety concerns, restrictions, and severity. Every condition's progression = "Follow the ACE-IFT Model."

| Condition | Page | Cardio (typical) | Resistance (typical) | Key safety rule to look up |
|---|---|---|---|---|
| CAD | p10–13 | 3–≥5 d/wk, 40–80% HRR, RPE 12–16 | 2–3 d/wk, 40–60% 1RM or 10–15 reps | HR ≥10 bpm **below** ischemic threshold; avoid Valsalva; physician clearance |
| Hypertension | p15–18 | ≥5 (pref. 7) d/wk, 40–60% HRR, below VT1 | 2–3 d/wk, 60–80% 1RM (40–50% older/novice), 2–4 × 8–12 | **avoid isometrics & inverted positions**; stop if SBP >250 or DBP >115, or SBP drops ≥20 with ↑ workload; prolonged cool-down; hydration on diuretics |
| Stroke | p19–22 | 3–5 d/wk, 40–70% HRR, RPE 11–14 | 2 d/wk, 50–70% 1RM, 1–3 × 8–15 | function/cognition deficits; equipment safety; recumbent options |
| PAD | p23–26 | 3–5 d/wk, moderate <VT1, to claudication pain **3–4, never exceed 4** | 2 d/wk, 60–80% 1RM | use the **claudication pain scale**, not %VO₂max; walk–rest–walk; footwear & foot checks |
| Dyslipidemia | p28–34 | ≥5 d/wk, <VT1 to <VT2, 40–75% HRR | 2–3 d/wk, 50–85% 1RM (strength) / <50% (endurance) | emphasize volume/caloric expenditure |
| Diabetes T1/T2 | p35–42 | 3–7 d/wk; T2 ≥150 min/wk moderate | ≥2 d/wk, 50–85% 1RM, 1–3 × 8–10 (10–15 to start) | start with blood glucose **≥100 and ≤250 mg/dL**; check before/during (30–60 min)/after; **15-15 rule** for hypoglycemia |
| Metabolic syndrome | p43–46 | ≥5 d/wk, <VT1, 40–60% HRR, maximize caloric expenditure | ≥2 d/wk, 50–85% 1RM | diagnosis = ≥3 of: ↑ fasting glucose, ↑ waist, ↓ HDL, ↑ BP, ↑ triglycerides |
| Asthma / COPD | p47–54 | 3–5 d/wk, <VT1 (40–60% HRR) → 60–70% if tolerated | ≥2 d/wk, 50–85% 1RM (start lower) | rescue medication on hand; **prolonged warm-up 10–15 min**; watch for EIB (peaks 5–10 min post); avoid triggers; mid–late morning best |
| Cancer | p55–61 | 3–5 d/wk, <VT1 to <VT2; 150 min/wk mod or 75 vig | 2–3 d/wk, **start <30% 1RM, progress ~5%** | nutrition/medical oversight; adjust for treatment fatigue & immune status |
| Osteoporosis | p62–67 | 4–5 d/wk, <VT1, 20–30 min (max 40–60) weight-bearing | 1–2 d/wk high-ish load 8–12 reps + 2–3 d/wk balance/functional | **avoid spinal flexion, twisting, compression; avoid high fall-risk / jarring moves**; emphasize bone-loading |
| Arthritis (OA/RA) | p68–73 | 3–5 d/wk, light→vigorous by conditioning; low-impact | 2–3 d/wk, 50–80% 1RM, 2–4 × 8–12, pain-free ROM | **RA: low-impact, limited ROM, warm water, avoid exercising during flare-ups**; start low |

## 19. Musculoskeletal issues *(Wk10 Ch15)*

### Healing phases & what movement is allowed *(p78)*
| Phase | Timeframe | Movement | |
|---|---|---|---|
| Inflammatory | 3–4 days | non-weight-bearing; gentle **pain-free** active ROM; RICE | |
| Repair / fibroblastic | 3 days – 6 wk | weight-bearing as tolerated; active ROM | |
| Remodeling / maturation | 4 wk – 2 yr | progressive **pain-free** exercise | |

**Contraindication throughout: any movement that causes pain or swelling at the injury site.**

### Post-rehabilitation training — Table 15-3 *(p89)*
Lower-extremity injury → train upper body seated/lying, spine/core without loading the injured limb, water-based; avoid weight-bearing until cleared. Upper-extremity injury → train lower body without involving the injured limb; avoid exercises needing both hands for stability. Back/spine → as prescribed by PT/physician, bodyweight as tolerated, avoid weighted spinal rotation, high reps, getting on/off the floor. Always: no pain-causing movement.

### Region program-design sequences (retrieve the exact steps)
- **Shoulder** *(p92)*: address posture / open subacromial space → strengthen scapular stabilizers (lower traps, rhomboids, serratus anterior, rotator cuff) → strengthen anterior shoulder (controlled pushing) → overhead work in the scapular plane (~30° anterior), modify ROM.
- **Elbow/wrist/hand** *(p96)*: limit overuse (vary grips, gloves) → gentle multi-planar ROM → strengthen wrist/hand → remove aids, add pulling volume as tolerated.
- **Neck** *(p99)*: posture assessment (neck/shoulder/thorax) → gentle movement & stretching → refer if pain persists/worsens.
- **Low back** *(p100–101)*: address faulty posture (thoracic + lumbar) → improve hip & thoracic ROM → strengthen posterior chain (glutes, hamstrings); stretch overactive, strengthen weak.
- **Hip** *(p106)*: address L/R imbalance → improve hip internal/external rotation ROM → single-leg stance stability → hip-hinge mobility & stability → posterior-chain strength.
- **Knee** *(p115)*: ROM & movement assessment (hip/ankle/foot alignment) → increase ROM, strengthen quads (bike) → correct L/R imbalance → address hip/ankle/foot tightness & instability → hip-hinge mobility → posterior-chain strength (partial-ROM squat, stiff-legged deadlift); **mostly avoid open-kinetic-chain knee exercises**.
- **Ankle/lower-leg** *(p123)*: foot & ankle mobility + stability → sagittal-plane strength → transverse/frontal-plane strength → posterior-chain strength; add balance training.

## 20. Assessment quick-reference

- **Sequencing** *(Wk04 Ch7 p22)*: resting → non-fatiguing (posture, flexibility, balance, vertical jump) → agility → max power/strength → sprint → local muscular endurance → anaerobic capacity → submax aerobic. Aerobic test ideally a separate day, else last after ≥1 h rest.
- **Pre-test** *(Wk04 Ch8 p70)*: 6–8 h sleep; no vigorous exercise 24 h prior; moderate food 2–4 h prior; hydrated; no HR-accelerating substances (except prescribed meds); proper attire; injury-free.
- **Stop a test** *(Wk04 Ch8 p71)*: angina; SBP drop >10 mmHg despite ↑ workload; SBP >250 or DBP >115; severe dyspnea/wheeze/claudication; poor perfusion signs; HR fails to rise; rhythm change; client asks to stop; severe fatigue; equipment failure.
- **Assessment contraindications to check first:** McGill flexor/lateral/extensor — low-back pain, recent back surgery, acute flare-up (+ shoulder pain for lateral; high body mass / strength deficits for extensor) *(Wk06 Ch10 p28–30)*; Y-Balance — not for older adults / balance-impaired *(p25)*; 1-RM bench — no shoulder-problem history, must show proper form *(p69)*; 1-RM squat — no low-back/knee pain, proper form *(p72)*; VT field tests — not for asthma/COPD, panic/anxiety, recent respiratory infection, insufficient fitness *(Wk04 Ch8 p74)*; power tests — not for special populations, orthopedic limitations, injury recovery *(Wk06 Ch10 p78)*.
- **Norms tables** live on: push-up p64, body-weight squat p67, 1-RM bench p71, vertical jump p81, unipedal stance p23 (all Wk06 Ch10); average ROM p33.
